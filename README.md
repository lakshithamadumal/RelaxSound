# 🎧 RelaxSound Studio

**RelaxSound Studio** is a 100% free web platform that lets you explore relaxing **ambient and meditation sounds** designed to help you **focus, sleep, and unwind**.  
Mix soothing elements like **rain, ocean waves, wind, and fire** to create your perfect soundscape — anywhere, anytime.

🌐 **Live Website:** [relaxsound.studio](https://www.relaxsound.studio)

---

## 🌙 Features
- 🎵 Mix and match ambient sounds  
- 🌿 Nature-inspired sound categories (Rain, Ocean, Wind, Fire)  
- 💻 Modern dark theme UI  
- 📱 Responsive and mobile-friendly design  
- 🧘 Focused on mindfulness and mental calm  
- 🚫 100% free

---

## 🛠️ Built With
- **HTML5**, **CSS3**, **JavaScript**  
- Custom **UI/UX Design**  
- Optimized for **SEO** and performance  
- Sound logic for ambient mixing and looping

---

## 🧠 About the Project
RelaxSound Studio was created to promote peace and mindfulness through sound therapy.  
The goal is simple — help users relax, meditate, or focus through naturally soothing audio experiences.

> *“Relax. Focus. Sleep. Repeat.”*
